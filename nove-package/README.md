# GPTM.nove

This is the source directory used to build the GPTM custom NOVE archive.

## Status

This package is a **scaffold**, not a runnable Geometry Dash mod yet. It has a manifest and packaging contract, but the compatible NOVE runtime and native game-side payload still need to be implemented.

## Package layout

- manifest.json — package metadata and supported-target declarations.
- payload/README.md — payload status and loader requirements.

Do not rename this archive to .geode or assume it is compatible with Geode. The .nove format is a separate custom format.
